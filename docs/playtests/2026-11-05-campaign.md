## Found and fixed

1. **The map screen's keys did not work.** The port panel covers the screen and stayed shown while shut, so every press on
   the HUD (Move here, End turn, Briefing, the port keys) went through it to the map, which picked a sector instead. Stills
   had set the screens directly, so nothing caught it. The port is now shown only while open (`MapScreen`).
2. **The map raced away under a drag**, about seven times as far as the pointer moved. A drag now keeps the point grabbed
   under the pointer (`CampaignMap.Pan`).
3. **A headless boot never finished**: the shader warm-up waited for a frame that a headless run never draws (`Prewarm`).

## Found, for the owner

- **A mission that travels with a fleet** (Assassination) keeps the fleet's course where it was set; the player sets course
  again from the briefing every turn until they meet. Mockup 1 does the same. Task `game-flow-engine` 1.12.
- **The battles are hard for a lone cruiser**: the scripted captain (lock, intercept, fire) drew both Stem the tide battles
  and lost the Assassination. A player who manages power and facings may do better; the captain does not.
- **Not covered yet:** the port in the script, phone size (task 1.6).
