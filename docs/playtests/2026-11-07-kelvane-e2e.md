## Found

- **The Kelvane ships were not imported on this Mac**: `ship model not found: res://assets/ships/kelvane/kelvane_cruiser.glb`.
  `scripts/playtest.sh` imports only when `.godot/imported` is missing, so a checkout that already has it never imports new
  assets. Fixed here by running the import; the script itself is unchanged (a stale import is a local state, the next
  `play.bat` or test run imports).
- **Warp and Escape**: the bot pressed the warp key at 24 % and 35 % risk and both jumps failed their roll (the warp field
  collapsed, nacelles damaged, banks drained). A jump is a roll against the shown risk, so whether these scenes pass depends on
  the scene's seed; the Concord's and Krai's pass on theirs the same way. The two Kelvane seeds were changed (20261309,
  20261310) and both now jump. The bot's jump rule (jump at 35 % or less, or 80 % with a foe within 90 km) is the same for
  every side.
- **Not Kelvane's, seen on every side**: Fighters ends with the target still alive (Concord too; the Krai win), Disable ends
  lost with its ship destroyed (Concord and Krai too), Repel runs out of time (the Concord's is lost). These are the scenes or
  the bot, not the Institute.
- **The Institute's officers carry the default names** (Lt. Sora Vance, Cdr. Ilse Moran): the officers' names and ranks are
  set per faction for the Krai and the Hunt only. Culture is the owner's to set (C4), so they stay until it is.
- **Phone portrait**: at 390 x 844 the console column and the view sit side by side, narrow, rather than the console stacked
  above the view (survey U2). Not checked against the other skins in this pass.
- **Stills of a scene with no enemy** (Relief) are not taken: still mode does not shoot one (the Krai's fails the same way).
  The transport station is shot on VIP instead.
