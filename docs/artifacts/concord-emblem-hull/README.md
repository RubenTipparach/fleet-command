# Concord emblem on the hull (mockup 11)

- Link: https://claude.ai/artifact/FLP6mnCeUCwn9c2rG2pxK9
- Shows: the Concord emblem B-E25 painted on the Concord line's Petrel frigate: a dorsal crest forward of the command
  block and one on each flank, 5.3 m tall (6 % of the ship's length), each under a logo floodlight, in the guide's two
  colour versions; views three quarter, dorsal, port flank and battle distance, with the mark's height on screen.
