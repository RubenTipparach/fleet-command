# Emblem Gallery

- Link: https://claude.ai/artifact/VdjoRwjMKG3Er8rC2H2epS
- Shows: every faction emblem built in 3D as its badge, Blender renders face on and at an angle, what it means and what it

  Krai Warhost (KC+, M14), the Ssarith Hunt (SD, M19). Owner, 2026-11-05: "create an emblem gallery artifact".
- Made by: `docs/mockups/emblem-gallery.html`, its pictures 640 px JPEGs from `tools/emblems/gallery_images.py`
  (`assets/emblems/gallery/`), inlined by `tools/mockups/inline_data.py`. Add a faction there when its badge is built.
